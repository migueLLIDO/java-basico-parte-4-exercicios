# Java Básico - Parte 4 (20 exercícios)

Seleção de 10 exercícios intermediários (31–40) e 10 avançados (41–50), com POO, modelagem, interfaces, composição, records, sealed types e SOLID.

## Execução

Requer JDK 17+. Compile e execute a classe desejada:

```powershell
javac -encoding UTF-8 -d out src/*.java
java -cp out NomeDaClasse
```

Cada exercício fica em uma classe independente dentro de `src/`.
